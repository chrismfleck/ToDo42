Share Lists

Share the list. Keep the spark.

Couples already build the perfect board in Save4Two. Next: let them gift that list — as a file in Messages, or as a link in an Instagram bio — so friends can open it and save the picks into their own Save4Two.

The final scenario

Chris & Deena plan an Asheville weekend in Save4Two — cabins, dinners, a hike. When the trip board feels right, they tap Share list. Save4Two builds a portable list package (titles, links, notes, categories). They can attach the file in a text to friends — or publish a link like save4two.com/l/asheville and drop it in an Instagram bio. A friend opens it, reviews the items in a familiar save screen, and adds what they want to their pair list. Private hearts and “done” checks stay private. Pairing stays pairing. This is a snapshot to share — not a second live couple sync.

Messages, Mail, AirDrop

Export creates Asheville-weekend.s4t.json. Attach and send. Recipient opens in Save4Two → import preview → save. Works offline. No website required.

Door B · URL

Instagram bio & anywhere links live

Same package, hosted at save4two.com/l/…. Web page for browsing; app fetches the list to import. One link for bios, Linktree, QR, Notes.
